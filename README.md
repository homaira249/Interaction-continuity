### Interaction Continuity

A User-Controlled Multimodal Desktop Environment Interaction Continuity is a browser-based project exploring how people interact with computers using different input methods. The idea is to create a simulated desktop environment where users can perform everyday tasks using a mouse, keyboard, or voice. They can switch between these input methods whenever they want without losing their current selections or task progress. 

I started this project out of an interest in Human-Computer Interaction and how small design decisions can affect the way people experience technology. In particular, I wanted to explore whether giving users more control over how they interact with a system could make the experience feel more natural and flexible. What I'm Exploring The project focuses on three main areas: Multimodal interaction: Using mouse, keyboard, and voice to complete tasks. Interaction continuity: Maintaining selections and unfinished actions when switching between input methods. User control: Letting users decide when and how to change their input method.

### The Prototype The simulated desktop is organized into five sections: 
Home — Introduction to the environment. Workspace — A place to perform everyday desktop tasks. 
Input Studio — Explore and switch between input methods.
Interaction Mirror — View and understand personal interaction patterns. 
Reflection — Share feedback about the experience.

### Research Approach
I plan to explore two interaction conditions: completing tasks using a single input method and completing tasks using multiple input methods with user-controlled switching. The comparison will focus on task completion, errors, switching behavior, and how users feel about the experience. With consent, interaction data will be recorded locally in the browser to help understand how people use the prototype. Users will also be able to reset their recorded data.
